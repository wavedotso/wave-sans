FONTLOG for Wave Sans
=====================

This file provides detailed information on the Wave Sans font software. This
information should be distributed along with the Wave Sans fonts and any
derivative works.


Basic font information
----------------------

Wave Sans is the typeface of Wave. It is a Modified Version of Inter 4.1 by
Rasmus Andersson, released under the SIL Open Font License 1.1 (see
LICENSE.txt). "Wave Sans" is a Reserved Font Name.

It covers Latin (including Vietnamese), Greek and Cyrillic in one variable
font, with a weight axis (100 to 900) and an optical size axis (14 to 32).
