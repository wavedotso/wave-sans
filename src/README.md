# Sources

- `WaveSans-Roman.glyphspackage`: upright masters, in [Glyphs](https://glyphsapp.com) 3 package format
- `WaveSans-Italic.glyphspackage`: italic masters, same format
- `features/`: OpenType feature code written by hand. The features Glyphs
  generates live inside the packages.

Building and verifying are described in the [README](../README.md).
